## 🎯 Quick summary (the whole topic in a nutshell)

Chemical equilibrium is about reactions that go **both ways at once** inside a closed container.
Reactants make products, products re-make reactants, and eventually both happen at the *same
speed* — so the amounts stop changing even though both reactions are still running. That balanced
state is equilibrium.

**The five things to really understand:**

1. **Equilibrium is dynamic, not stopped.** The forward and reverse reactions are both still
   going; they're just equally fast, so concentrations stay constant. Nothing has frozen.
2. **The equilibrium constant $K$ is a fixed ratio.** $K_c = \dfrac{[\text{products}]}{[\text{reactants}]}$,
   each raised to its coefficient. A big $K$ means "mostly products"; a small $K$ means "mostly
   reactants." $K$ depends on **temperature only** — not on how much you started with, not on
   pressure, not on a catalyst.
3. **$K_p$ and $K_c$ are linked by $K_p = K_c(RT)^{\Delta n}$**, where $\Delta n$ counts only gas
   moles (products minus reactants). If $\Delta n = 0$ they're equal.
4. **$Q$ tells you which way it will go.** Compute the same ratio with *current* amounts: if
   $Q < K$ it moves forward, if $Q > K$ it moves backward, if $Q = K$ it's already balanced.
5. **Le Chatelier predicts every "what if".** Disturb an equilibrium and it shifts to partly undo
   the disturbance — add a reactant → forward; squeeze (↑ pressure) → fewer-gas-moles side; heat
   it → endothermic direction. Only temperature actually changes $K$; everything else just moves
   the position.

**The one tool for numericals:** the **ICE table** (Initial / Change / Equilibrium in moles),
then convert to concentration or pressure and substitute into $K$.
