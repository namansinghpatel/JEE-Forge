Foundations

1Dynamic equilibrium

\(\text{rate}_{fwd}=\text{rate}_{rev}\)
Both reactions still run — amounts constant, not equal. Closed system only.

2Equilibrium constant \(K_c\)

\[K_c=\dfrac{[C]^c[D]^d}{[A]^a[B]^b}\]
Products over reactants, each to its power. T only.

3\(K_p\) (gases)

\(K_p=\dfrac{(p_C)^c(p_D)^d}{(p_A)^a(p_B)^b}\)
Partial pressures instead of concentrations.

4\(K_p\)–\(K_c\) link

\[K_p=K_c(RT)^{\Delta n}\]
\(\Delta n\)=gas moles (prod−react). \(\Delta n=0\Rightarrow K_p=K_c\).

5Meaning of \(K\)

K ≫ 1 products  K ≪ 1 reactants. Units \((\text{mol/L})^{\Delta n}\).

6Heterogeneous

Omit pure solids & liquids — e.g. \(\text{CaCO}_3(s)\rightleftharpoons\text{CaO}(s)+\text{CO}_2(g)\Rightarrow K_c=[\text{CO}_2]\).

Quantify It

7Manipulating \(K\)

reverse\(1/K\)
×n coeff\(K^n\)
add rxns\(K_1K_2\)

8Temperature on \(K\)

Exo: \(T\uparrow\Rightarrow K\downarrow\). Endo: \(T\uparrow\Rightarrow K\uparrow\).

9Reaction quotient \(Q\)

\(QK\Rightarrow\leftarrow\)
Same form, current values.

10Degree of dissociation

\(K_p=\dfrac{\alpha^2}{1-\alpha^2}P\ \ (A\rightleftharpoons B+C)\)
Set up with an ICE table.

11Case \(A\rightleftharpoons 2B\)

\(K_p=\dfrac{4\alpha^2}{1-\alpha^2}P\)
The factor 4 — don't mix the two.

12Vapour density → α

\(\alpha=\dfrac{D-d}{(n-1)d}\)
Dissociation lowers vapour density.

Le Chatelier — shift to oppose

13Concentration

Add reactant → forward; add product → backward.

14Pressure / volume

↑P → fewer-gas-moles side. \(\Delta n=0\): no effect.

15Temperature

Heating → endothermic direction — the only thing that changes \(K\).

16Catalyst & inert gas

Catalyst: no shift. Inert gas at const V: no shift.

Traps

17Top mistakes

forgetting to divide moles by V; solids in \(K\); wrong α-formula; \(R\) not matching the pressure unit.

18Inert-gas trap

Const volume → partial pressures unchanged → no shift, though total P rises.

193-step solve

balanced eqn → ICE table → convert → substitute.
