## 🎯 Quick summary (the whole topic in a nutshell)

This chapter is the **language of mathematics** — sets, relations and functions are the vocabulary every
later topic is written in (domains in calculus, mappings in algebra, equivalence in number theory).

**The seven things to really understand:**

1. **Sets & operations:** union, intersection, difference, complement; **De Morgan's laws**. A set of $n$
   elements has $2^n$ subsets.
2. **Inclusion–exclusion:** $n(A\cup B) = n(A)+n(B)-n(A\cap B)$ — the tool for every "both/neither/exactly
   one" survey problem (draw a Venn diagram).
3. **Relations:** a relation is a subset of $A\times B$. On a set, check **reflexive, symmetric,
   transitive**; all three = **equivalence relation** (it partitions the set).
4. **Functions:** each input maps to exactly one output. Know **domain, codomain, range** (range ⊆
   codomain).
5. **Types:** one-one (injective), onto (surjective), bijective (both → invertible), many-one, into.
6. **Composition & inverse:** $(g\circ f)(x) = g(f(x))$ (not commutative); inverse exists **iff bijective**,
   with $(g\circ f)^{-1} = f^{-1}\circ g^{-1}$.
7. **Domain is a checklist:** no zero denominators, non-negative even roots, positive logs — then intersect.

**The master trick (advanced):** the **counting formulas** — $2^m$ subsets, $2^{mn}$ relations, $n^m$
functions, ${}^nP_m$ injective functions — and the **discriminant method** for finding a rational
function's range. Equivalence relations **partition** a set into classes (the bridge to modular arithmetic).
